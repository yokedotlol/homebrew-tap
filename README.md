# Homebrew Tap for Yoke

Domain intelligence in one pass — DNS, WHOIS, SSL, security, tech stack, performance, breaches, and AI analysis.

## Install

```bash
brew install yokedotlol/tap/yoke
```

## About

This tap is automatically updated by [GoReleaser](https://goreleaser.com) on each [Yoke release](https://github.com/yokedotlol/yoke/releases).

For more info: [yoke.lol](https://yoke.lol) · [GitHub](https://github.com/yokedotlol/yoke)
